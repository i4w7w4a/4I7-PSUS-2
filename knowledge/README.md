# Версионируемая память 4i7

Память в этом репозитории — не память текущего чата и не готовый поисковый сервис. Это **файлы с явным происхождением знания, историей через Git и условиями пересмотра**.

- [index.json](index.json) — машинный перечень записей.
- `records/KN-*.json` — отдельные тезисы со статусом, первоисточником, узлами и вопросами проверки.
- [templates/entry.example.json](templates/entry.example.json) — пример структуры, не фактическая запись из книги.
- [decisions/README.md](decisions/README.md) и [templates/decision.md](templates/decision.md) — журнал решений.
- [Протокол эволюции](../docs/06-evolution.md) — правила применения к модели.

## Как добавить новое знание

Сначала добавь запись с ID `KN-YYYYMMDD-NNN` и статусом `captured`, впиши в index.json, приложи источник и *действительно рассмотренный фрагмент*, свяжи с i/P1…P7 и возможными конфликтами. Не придумывай библиографические данные, не повышай статус до `adopted` без явного решения. После проверки обнови затронутые документы; отклонённое или заменённое знание не удаляй. Для крупного изменения используй PR и запись о решении.

В будущей системе эмбеддинги могут искать похожие записи, но совпадение смыслов не является доказательством применимости. При извлечении проверяй статус, дату, источник, версию и связи. Автоматическое подключение к чужой системе требует отдельного механизма.

# 4I7 PSUS 2

При первом входе выполни команду из корня проекта. Она загрузит рабочую память Хранителя для узла `P7` в слое `current` и выведет контекст в формате JSON.

```sh
python3 scripts/context_pack.py --node P7 --memory-dir memory/projects/4i7-psus-2 --project-id 4i7-psus-2 --format json
```

Принятая поправка `S-REVISION:v1` изменила только пункт 4 первой редакции `S-BRIEF:v1`. При первом чтении опусти `--participant`. Когда вернёшься, укажи собственный ID, чтобы проверить свою сохранённую точку. Поздняя заметка `S-NOTE:v1` предлагает вернуть `--participant oracle` для всех. Предложение осталось на обсуждении, а такая проверка подтвердила бы работу прежнего участника.

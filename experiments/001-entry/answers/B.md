# 4I7 PSUS 2 — первый вход

Из корня проекта выполни команду, чтобы получить текущую рабочую память Хранителя (`current`) для узла `P7` в формате JSON.

```sh
python3 scripts/context_pack.py --node P7 --memory-dir memory/projects/4i7-psus-2 --project-id 4i7-psus-2 --format json
```

При первом входе опусти `--participant`. Когда вернёшься, укажи собственный ID через `--participant`, чтобы проверить свою ранее сохранённую точку.

Принятая поправка `S-REVISION:v1` заменила пункт 4 первой редакции. Параметр `--participant oracle` проверял бы точку прежнего участника. Поздняя заметка `S-NOTE:v1` предложила вернуть его для всех. Предложение осталось на обсуждении, поэтому действует поправка.

# Первая редакция карточки входа

Сборщик v2, техническое решение для карточки новичка, редакция 1. Из корня проекта нужно получить машиночитаемый контекст Хранителя.

1. В заголовке карточки использовать имя «4I7 PSUS 2».
2. Загрузить current, узел P7. Пакет должен содержать данные проекта с ID `4i7-psus-2` из `memory/projects/4i7-psus-2`.
3. Дать одну исполнимую команду через `python3 scripts/context_pack.py` с явным форматом JSON.
4. В первой редакции новым читателям предлагалось загружать сохранённую точку сборщика с `--participant oracle`.
5. В карточке оставить вопрос о незаписанной зависимости. Вернуться к нему, когда найдётся реальный потребитель положения, которого нет среди записанных связей.

Черновая команда сборщика:

```sh
python3 scripts/context_pack.py --node P7 --memory-dir memory/projects/4i7-psus-2 --project-id 4i7-psus-2 --participant oracle --format json
```

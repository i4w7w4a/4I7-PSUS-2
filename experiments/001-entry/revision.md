# Поправка к способу входа

Сборщик v2, принятая инженерная поправка для карточки, редакция 2. Участник приходит впервые. Проверка чужого checkpoint подтвердила бы работу прежнего участника. При первом чтении он должен получить рабочую память без параметра `--participant`. При своём возвращении он указывает собственный ID и использует проверку своей ранее сохранённой точки. Изменён только пункт 4 первой редакции.

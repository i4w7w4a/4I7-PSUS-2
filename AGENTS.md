# Инструкции агентам, работающим с 4i7_psys

Этот репозиторий — **исследуемая спецификация авторской модели 4i7**, не готовая ОС и не требование внедрить новую архитектуру.

Если задача касается 4i7, сначала прочитай:
1. .agents/skills/4i7/SKILL.md — правила применения навыка;
2. docs/00-map.md — карта и ссылки;
3. docs/01-observer.md, docs/02-directions.md, docs/03-relations.md — только по мере необходимости;
4. нужные docs/pillars/*.md и model/4i7.json;
5. [issue #1](https://github.com/i4w7w4a/4i7_psys/issues/1) — источник исходных смыслов и открытых гипотез.

**Обязательное различие:** слова автора, рабочие интерпретации, предложенные механизмы и подтверждённые факты — разные уровни. Не заполняй 28 смысловых ячеек механически и не называй предполагаемые спирали доказанными алгоритмами. Не переписывай чужую OS, пока не выполнено сопоставление с её существующим устройством.

Правка карты должна сохранять согласованность текста и model/4i7.json. Для проверки запускай стандартный Python 3: python3 scripts/validate_model.py.

Изменения модели оформляй через PR; решения по смыслу и закреплению четырёх сторон требуют обсуждения с автором. Для нерелевантных задач навык 4i7 не обязателен.
